# RankLens（排名截圖辨識器）

RankLens 是非官方、離線執行的 Windows 桌面應用程式，用於校對排名截圖並將確認後的資料匯出至 Excel。

> 本專案與 Last War: Survival Game 的開發商或發行商沒有隸屬、認可或贊助關係。

## 目前狀態

目前已具備 .NET 10 WPF 基線、圖片選取／批次取消、候選列勾選與編輯、Open XML 活頁簿建立／安全更新、CPU 離線 OCR、設定與隱私安全 Log。PP-OCRv5 ONNX GPU 推論管線、完整模型包與正式 ZIP 發佈仍待模型來源與雜湊完成；在此之前可用同名 `.txt` 側錄預覽流程。
